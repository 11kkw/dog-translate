Dog Translate portable distribution

1. Run DogTranslate.exe.
2. Choose ChatGPT or Claude under "번역 계정".
3. Complete the official provider login in your browser.

ChatGPT
- The portable package includes the native Codex runtime, so Node.js and an API key are not required.
- A ChatGPT account with Codex access is required.

Claude
- Install the official Claude Code application first, then choose Claude in Dog Translate.
- Claude Pro, Max, Team, Enterprise, or Console access is required. The free Claude plan does not include Claude Code.
- Dog Translate does not redistribute Anthropic's executable. It detects the official Claude Code installation or DOG_TRANSLATE_CLAUDE_PATH.

Privacy
- Captured screenshots remain in memory and are processed by the operating-system OCR engine.
- Only extracted text is sent to the selected translation provider.

Licenses
- Dog Translate is licensed under Apache-2.0. See LICENSE.txt.
- Third-party license notices are in NOTICE and THIRD_PARTY_LICENSES.html.

Keyboard shortcuts
- Windows: Ctrl+T, Ctrl+B, Esc
- Esc cancels area selection or the active overlay and keeps Dog Translate hidden in the background.
- macOS: Command+T, Command+B

macOS permissions
- Allow Screen Recording when macOS asks so Dog Translate can capture the selected region.
- Allow Accessibility so selection translation can copy the highlighted text with Command+C.
